# The LLM Fieldguide

A 30-chapter interactive course on language models, from first principles to banking product decisions.

Includes dark mode, interactive diagrams, learning experiments, quizzes, a glossary, and browser-local notes and progress. No server, API keys, or model calls are required. All banking examples are fictional.

## Hosting
GitHub Pages publishes the repository root from the main branch. Edit the HTML, CSS, JavaScript, or lesson content and push to main to update the website.

## Local preview
Serve this directory using any static HTTP server. All asset paths are relative so the course supports a GitHub Pages project URL.

## Data
Notes, completion, and theme preferences are stored only in the visitor's browser. They do not sync across devices or transfer automatically from another domain.

## Content
Provider comparisons are a dated snapshot from 4 October 2026. Source links are included in the course. Verify official documentation before updating model claims.
